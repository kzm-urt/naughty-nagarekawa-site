# NAUGHTY Nagarekawa Site

NAUGHTY公式サイトの公開用リポジトリです。

## 公開先

XServer Staticとこのリポジトリを連携し、リポジトリ直下を公開ディレクトリとして使用します。

## 更新方法

1. ローカルで表示を確認する
2. 公開用データに給与・売上・従業員情報・認証情報が含まれていないことを確認する
3. GitHubへコミットしてプッシュする
4. XServer Staticの自動デプロイ完了後に本番URLを確認する

## 公開境界

このリポジトリには公開サイトに必要なHTML、CSS、JavaScript、画像だけを保存します。
CMS、従業員ポータル、給与・売上データ、バックアップ、Supabaseのサービスロールキーは追加しません。

現在のCMS連携用設定は `shared/runtime-config.js` の公開可能な接続項目のみを使用します。
